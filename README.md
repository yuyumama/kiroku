# kiroku

Kiro CLI（V3）での開発中に起きた失敗や手直しを記録し、ハーネスの改善案を出すための仕組みです。

- 使い方：[docs/retro/README.md](docs/retro/README.md)
- 検証の結果：[docs/retro/verification.md](docs/retro/verification.md)

| 場所 | 中身 |
|---|---|
| `kit/` | 導入先のリポジトリにコピーするファイル |
| `install.sh` | 導入スクリプト |
| `examples/demo/` | 動作確認用のサンプル |
| `tests/` | テスト |
| `probe/` | 段階1で使った検証キット |
