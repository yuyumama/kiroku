# カテゴリを追加する

1. `kakeibo/models.py` の `CATEGORIES` に、新しいカテゴリを足します。「その他」は最後のままにします。
2. `tests/test_models.py` に、新しいカテゴリで記録できることを確かめるテストを足します。
3. `tests/test_report.py` の集計の順が変わらないことを確かめます。集計は `CATEGORIES` の順に並びます。
4. `README.md` にカテゴリの一覧は書いていないので、直しません。
5. テストを実行し、すべて通ることを確かめます。

既に記録に使われているカテゴリの名前は変えません。過去の記録が読めなくなるためです。
