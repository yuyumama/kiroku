# kakeibo の前提

支出を記録し、月ごとに集計する家計簿の CLI です。個人が手元で使うもので、サーバーやデータベースは使いません。

## 決まり

- 外部のパッケージを足しません。Python の標準ライブラリだけで書きます。利用者に `pip install` を求めないためです。
- 金額は整数の円で持ちます。小数は使いません。端数の誤差を出さないためです。
- 利用者に見える文言（メッセージ、エラー、ヘルプ）は日本語で書きます。
- 入力の検査は `kakeibo/models.py` の `make_entry` に集めます。CLI や保存の側で、同じ検査を書き直しません。
- 記録の保存先は `data/kakeibo.json` です。`data/` は git に載せません。
